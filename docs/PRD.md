# PRD: Family TokTok (우리가족 톡톡)

## 목표

초등학생 자녀와 부모가 광고·외부인 없이 안전하게 대화하고, 기분과 칭찬을 주고받는 가족 전용 앱을 만든다.

## 사용자

초등학생(만 7~12세) 자녀가 한 명 이상 있는 가족. 보호자는 부모뿐 아니라 조부모 등 다른 보호자도 포함될 수 있다.

## 핵심 기능 (1차 출시 MVP)

1. 가족 만들기와 초대 (부모가 가족 생성, 초대 코드/QR로 보호자 초대, 아이 계정은 부모가 생성)
2. 아이 로그인 (이메일/비밀번호 없이 부모 폰 QR 스캔으로 기기 연결)
3. 대화 (가족방 + 아이별 1:1 방, 글/스티커/반응, 빠른 답장 버튼, 안읽음 표시)
4. 긴급 버튼 ("데리러 와주세요"/"도와주세요" → 1:1 방 메시지 + 방해금지 모드 우회 강한 푸시)
5. 오늘의 기분 (이모지 5개 중 선택 + 이유, 슬픔/화남 선택 시 1:1 방으로 부모 알림, 일주일 기록)
6. 칭찬판 (아이별 스티커 10개 판 + 보상 목표, 여러 아이 동시 칭찬, 목표 달성 후 새 판)
7. 오늘의 가족 질문 (가족방 상단에 매일 새 질문)
8. 푸시 알림 (새 메시지, 긴급 메시지, 칭찬)

## MVP 제외 사항

- 사진 전송, 음성 메시지, 사용 시간 제한, 가족 일정/준비물 체크리스트, 월별 기분 리포트 → 2차 출시
- 위치 알림, 조부모 큰 글씨 모드, 가족 앨범 → 나중에 고려
- 공개 프로필, 친구 찾기, 가족 밖 공유, 광고, 좋아요 순위, 형제 비교 화면 → 영구 제외 (`Family-TokTok-프로젝트-기획서.md` 4장 참조)

## 디자인
